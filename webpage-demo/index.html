What Lodestone is

A panel for people who run a server for their friends

Everything your server does, in one window, in plain English.

Lodestone is a control panel for Minecraft servers, the ones you and your friends play on. Start and stop a server, read the console, edit config files, see who is online, roll back to a backup, all from a browser.

It is built for small communities rather than hosting companies: plain language instead of jargon, defaults that already make sense, and nothing important hidden behind a paid tier.

Waypoint 02 The roadmap, in order

Planned features

Eight things the panel will do

01

Live console

Watch the log as it happens and type commands straight into it, No SSH needed

02

File manager

Edit server.properties, configs and datapacks in the browser. A copy is kept before every save.

03

Players

See who is online, hand out operator rights, kick or ban someone without digging through the console.

04

Backups and restore

Snapshots on a schedule, and a way back to yesterday when a build goes wrong.

05

Mods and modpacks

Install a pack, check the versions line up, and find the mod that stopped the server booting.

06

World map

A view from above with player positions, waypoints and the places your community cares about.

07

Scheduled tasks

Restart at 4am, announce an event, run a backup before the weekend. Set it once.

08

Several servers

Survival, creative and modded side by side, each with its own status and history.

Waypoint 03 The theme, in order

Haunted Harvest

A spooky theme for week 01

A theme for the first week of the project, with a few surprises.

The first week of Lodestone is a Halloween theme, with a few surprises hidden in the code. The compass spins, leaves fall, and the background is haunted. Check the source code for more.

There are also some accessibility features: a high contrast mode, a motion reduction mode, and a font size adjustment. These can be toggled in the accessibility dialog.
