# Theme Ideas

We are planning to make the default theme for lodestone Neumorphism, this will include details such as soft colours like pale and muted, pastel color palettes

The UI will also include dual shadows around certain UI elements like buttons and labels, with a light shadow on the top left and dark shadow on the top right to simulate depth/make elements look extruded from the page

This design is visually appealing and makes the page clean, modern and tactile but I have concerns about the accessibility issues so an alternative theme that is more accessible should be the first option availible in the setup
